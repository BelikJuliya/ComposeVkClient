Приложение с мобильным клиентом ВК с тремя табами: список новостей с комментариями, избранное, профиль. Также реализована авторизация через ВК.
Приложение полностью на Compose. Для DI использован даггер. Разделение на модули пока не реализовано. Данные тянутся с бека через VK API. Архитектура MVVM + Flow. Многопоточность на корутинах.
Некоторые методы апи устарели и перестали поддерживаться, поэтмоу временно добавлены моковые данные.
